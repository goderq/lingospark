# LingoSpark для iPhone

## Лицензии и админ-панель — версия 4.7.0

Лицензия выдаётся аккаунту после активации промокода. После проверки лицензии занятия работают офлайн до семи дней или до окончания лицензии, если оно наступит раньше. Активация, управление доступом и смена имени требуют подключения. Приложение проверяет изменения при возвращении на экран и каждую минуту во время работы.

В «Профиль → Админ-панель» можно создать временный или бессрочный промокод, ограничить число активаций и срок действия кода, отключить код или отозвать лицензию у конкретного аккаунта. Отключение кода сохраняет выданные лицензии. Один аккаунт может активировать каждый код один раз. Полный код показывается при создании, в базе хранится его хеш.

Первого владельца назначают в SQL Editor Supabase по точному адресу подтверждённого аккаунта. Замени `owner@example.com` перед запуском. Запрос возвращает ID и роль назначенного владельца. Владелец назначает и снимает администраторов в приложении через поиск аккаунта по почте.

```sql
insert into lingo_access.staff (user_id, role)
select id, 'owner'
from auth.users
where lower(email) = lower('owner@example.com')
  and email_confirmed_at is not null
  and not is_anonymous
on conflict (user_id) do update set role = excluded.role
returning user_id, role;
```

Миграция находится в `supabase/migrations` и использует существующую таблицу `public.profiles`. Имя синхронизируется с аккаунтом при регистрации и после сохранения в «Профиль → Настройки профиля и обучения». Проверка лицензии на устройстве появилась с версии 4.7.0.

## Контекст офлайн-разговора — версия 4.6.2

Обычный чат передаёт модели до шести последних сообщений и до двух более ранних фактов из текущего диалога. Для короткого ответа или уточнения в инструкции сохраняется предыдущий вопрос. Грамматическая справка добавляется при явном запросе или при совпадении с известной ошибкой. Ролевые сцены, собеседования и действия над ответом продолжают получать свои инструкции.

В «Профиль → Диагностика» можно сравнить установленные Gemma 3 · 1B и Llama 3.2 · 1B на трёх одинаковых примерах. Отчёт содержит реплики, время после загрузки модели и ошибки. Сравнение работает локально на подготовленных фразах, выбранная модель не меняется. Автотесты проверяют передачу контекста с подставленным движком.

## Начало офлайн-диалога — версия 4.6.1

После первого отдельного приветствия в свободном разговоре, путешествиях или теме работы приложение сразу задаёт подходящий английский вопрос. Это локальное продолжение вступления, дальше отвечает модель. Фильтр повторов допускает приветствие в начале содержательной реплики. Карточка ошибки показывает текст отдельно от кнопок, а диагностика отличает первый токен отдельной попытки от времени до готового ответа.

## Гибкие ответы в диалогах — версия 4.6.0

Проверка коротких диалогов принимает больше естественных английских формулировок. В правилах сохраняются смысл просьбы, день, время и другие важные детали. Например, запись можно перенести с помощью `move`, `change` или `reschedule`. Ответ с другим днём не засчитывается. После ошибки можно исправить текущую реплику, сохранив написанный текст. Итог отдельно учитывает ответы после исправления или подсказки.

На повторной самопроверке меняются 22 вопроса. Для 15 из них в этой версии добавлены по две новые ситуации. Базовые тесты и правила открытия следующих тем сохраняются.

## Llama и Gemma в каталоге — версия 4.4.0

Текущие исходники: 4.4.0, iOS build 45. В разделе локальных моделей появились три основных варианта: «Лёгкий» — Llama 3.2 1B Instruct Q4_K_M (808 МБ), «Обычный» — Gemma 3 1B IT Q4_K_M (806 МБ), «Продвинутый» — Llama 3.2 3B Instruct Q4_K_M (2,02 ГБ). Установка начинается только по нажатию в каталоге; веса не входят в приложение. Названия режимов не являются результатом сравнительного тестирования качества. Llama 1B предложена для первого знакомства с новыми моделями; фактические скорость, качество русского и нагрев нужно проверить на iPhone.

У моделей новые ID и отдельные файлы. Старые Qwen с ID `light`, `standard`, `advanced` сохранены: установленные/активные видны сразу, остальные открываются по «Показать прежние модели Qwen». Просмотр каталога не меняет выбранную модель. Успешное скачивание выбирает загруженную модель как прежде; для открытия чата нужно нажать «Выбрать и запустить». История и незавершённые загрузки старых моделей не переназначаются на новые веса. В шапке чата, голосовом режиме и диагностике видно настоящее имя модели.

Файлы новых моделей закреплены на конкретных коммитах публичных репозиториев bartowski. Через HTTP Range проверены доступ без аккаунта, размер и первые четыре байта GGUF каждого URL. Загрузчик сверяет точный размер новой версии и заголовок; SHA-256 из LFS записан в манифест для происхождения файла, но хеш всего файла на телефоне не вычисляется. Для Llama, Gemma и Qwen выбраны разные маркеры остановки; используются встроенные шаблоны GGUF через Jinja с fallback движка. Gemma получает системные инструкции внутри первого сообщения пользователя после ограничения контекста. Последовательные сообщения одной роли объединяются. Эти настройки общие для чата, переформулировки, JSON-разбора и голосового режима.

Карточки содержат источник и условия конкретной семьи. Лицензия Llama доступна прямо в приложении без интернета, добавлены её копия и атрибуция Built with Llama. Gemma открывает официальные Gemma Terms, прежний Qwen 3B — Qwen Research License; Qwen 0.5B/1.5B — Apache 2.0. Не используется прежняя общая подпись Apache для всех моделей.

Проверки: `test:ai-models` (каталог, совместимость ID, скачивания/ошибки/пауза/продолжение), `test:tutor-reply` (все шесть моделей, A1–C1, язык и переформулировка с подставленным native engine), `test:interface` (каталог, ручное скачивание, прежняя модель, условия, темы), `test:architecture`. Подробнее: [docs/models-4.4.md](docs/models-4.4.md). Реальная генерация GGUF требует проверки на iPhone; IPA и публикация Expo не запускались.

## Английский диалог и простой старт — версия 4.3.0

Текущие исходники: 4.3.0, iOS build 44. На «Сегодня» один главный вход в короткое занятие, текущая тема со следующим этапом, повторение и переход «Все занятия» в «Обучение». Убраны дублирующая сетка навыков и дополнительный раскрываемый план с теми же входами. Сами упражнения сохранены в разделе обучения. В маршруте темы видны прогресс, текущий этап и условие открытия следующей темы; длинные пояснения вынесены под кнопку. В объяснении ошибки сначала показывается конкретное отличие ответа, затем допустимый образец; правило, примеры и закрепление остаются доступны.

Исправлены две причины ответов со скриншота: прежние инструкции поощряли русский на A1–A2, а проверка повторов исключала короткие реплики. Основной диалог теперь запрашивается на английском на всех уровнях, русский разрешается для явного перевода/объяснения или соответствующего действия. Системный запрос стал короче; обязательное правило языка остаётся в его конце после контекста курса. Русский текст старого приветствия не используется как пример беседы. Короткие приветствия не получают случайную грамматическую справку. Ответ проверяется на язык, повтор недавней реплики/вопроса и технический мусор; разрешена одна попытка переформулировать, результат проверяется заново. Невалидный черновик не выводится потоком и не заменяется заготовленным приветствием. Если исправление не удалось, показана ошибка с ручным повтором без дублирования сообщения ученика.

Ложные отметки «Проверено по контексту» и «Опора на справочник» убраны: эти проверки не доказывают смысловую или грамматическую правильность. Qwen 2.5 0.5B/1.5B/3B и скачанные файлы не менялись; качество другой модели не заявляется без сравнения на устройстве. Доступны состояния загрузки, обдумывания, проверки, переформулировки, слушания и остановки. Поздний результат остановленного запроса игнорируется. История виртуализирована и ограничена 60 сообщениями; повторные анимации прокрутки на каждом токене убраны. Сохранение в тетрадь и оценка ответа находятся под «Действия», подробности миссии свёрнуты.

Поле чата использует измеренную позицию контейнера и конечную координату клавиатуры в окне. Удалена отдельная iOS accessory-панель; больше нет сравнения локального y с абсолютной координатой клавиатуры. При открытой клавиатуре скрыты полосы выбора темы и режима; в шапке есть кнопка скрытия клавиатуры. Проверки измерения, остановки/повтора запроса и маршрутов: `test:interface`; реальные вызовы сервиса с подставленным native engine, язык A1–C1 и ограниченный повтор: `test:tutor-reply`. Проверка на физическом iPhone ещё нужна. Подробнее: [docs/chat-4.3.md](docs/chat-4.3.md). IPA и Expo-публикация не запускались.

## Контрастные кнопки и розовая тема — версия 4.1.0

Текущие исходники: 4.1.0, iOS build 42. Исправлен экран темы: второстепенные действия теперь используют общий компонент кнопки с контрастным текстом, светлой/тёмной поверхностью и заметной рамкой. Маршрут не открывает следующий курс автоматически: сам урок курса проходится отдельно, после него доступны прежние проверки памяти.

Из маршрута можно открыть локальный ИИ с темой, целью и первой репликой знакомства. Установка модели остаётся добровольной через библиотеку ИИ; учебные этапы работают без неё. В обычных курсах убраны жизни и принудительный перезапуск. Неверные ответы разбираются после основных вопросов; к завершению можно перейти после правильного ответа в разборе. В мини-разговоре ошибка требует повторной реплики и остаётся ошибкой в исходной точности. Черновик курса сохраняет ответы, счёт, порядок вариантов, разбор и шаг разговора. Старый черновик без результатов или черновик от другой версии содержания начинается сначала, чтобы не выдумывать точность. Завершённые уроки сохраняются.

Во временах и академии грамматики также убраны жизни; прохождение засчитывается от 80%. Экзаменационные режимы сохранены. Полный формат из пяти этапов пока подготовлен для одной темы. Остальные 42 курса и разделы доступны в существующем формате; их смысловая переработка ещё предстоит. Добавлены замеры первого кадра новых экранов. Проверки: `npm run test:learning-journey`, `npm run test:cloud-sync`, учебные аудиты и экспорт JavaScript для iOS. После прохождения урока через 24 часа становится доступна отдельная проверка: до пяти вопросов с выбором ответа из этого урока, в случайном порядке. Подсказки, правильные ответы и промежуточная оценка скрыты до завершения. Успешная проверка (от 80%) назначает следующую через три дня; после двух успешных проверок подряд урок получает отметку «Закреплено», дальнейший интервал — семь дней. Неуспех снимает эту отметку и назначает повтор через день. Это учебный индикатор по выборочным вопросам, а не доказательство владения темой.

Старые пройденные уроки получают первую проверку через день после обновления: прошлую дату прохождения не угадываем. Расписание и результаты входят в обычное сохранение прогресса и резервную копию. Проверки не меняют доступ к урокам и не начисляют повторно XP курса. Выход из незавершённой проверки не засчитывает попытку.

Проверка: `npm run test:retention`. Нативный интерфейс на iPhone ещё нужно проверить; IPA не собиралась.

## Установка IPA через Sideloadly

1. Установите Sideloadly на Windows или macOS.
2. Подключите iPhone кабелем и подтвердите доверие компьютеру.
3. Перетащите файл `LingoSpark-unsigned.ipa` в Sideloadly.
4. Укажите Apple ID и нажмите **Start**.
5. На iPhone включите режим разработчика и доверьтесь профилю Apple ID.

Приложение работает офлайн: Expo Go и постоянное подключение к компьютеру не нужны. Необязательный аккаунт Supabase сохраняет прогресс в облаке; интернет требуется только для входа и синхронизации. При бесплатном Apple ID подпись нужно обновлять каждые 7 дней.

## Создание следующей IPA

### GitHub Actions (ручная сборка)

1. В репозитории откройте **Actions → iOS IPA for Sideloadly**.
2. Нажмите **Run workflow**, выберите ветку `main` и подтвердите запуск.
3. После успешной сборки откройте её страницу и скачайте архив из **Artifacts → LingoSpark-unsigned-IPA-…**.
4. Распакуйте ZIP и установите находящийся внутри `.ipa` через Sideloadly.

Workflow запускается только вручную. Коммиты и загрузка кода не запускают сборку.
Используется виртуальный Mac GitHub (`macos-26`), Xcode и CocoaPods; учётная запись Expo и лимит EAS Build не используются.
Сборка создаёт неподписанный IPA для физического iPhone, не для симулятора. Подпись добавляет Sideloadly при установке. Apple ID, пароль и сертификаты в GitHub загружать не нужно.

Проверены структура workflow, локальная сборка JavaScript и учебные проверки. Первый полный запуск на macOS ещё нужно проверить вручную: Linux-среда не позволяет выполнить Xcode. Доступность и стоимость macOS-минут зависят от текущих условий GitHub Actions и настроек аккаунта.

Скрипт `bash scripts/build-ios-unsigned.sh` можно запустить и на своём Mac после `npm ci`, `npx expo prebuild --platform ios --no-install` и `cd ios && pod install` (затем вернуться в корень проекта).

### Ранее использовавшаяся сборка EAS

Команда `npm run build:ipa` использует EAS Build и его квоту. Профиль `sideloadly` компилирует arm64-приложение без Apple-подписи и упаковывает его в IPA.

Релизы Expo Snack для проекта не создаются.
