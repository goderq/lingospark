# LingoSpark для iPhone

Словарная база пересобрана из FreeDict English–Russian 2025.11.23 (CC BY-SA 3.0) и билингвального словаря MUSE (CC BY-NC 4.0). Частые служебные слова и неправильные омонимы проверены вручную. База хранится внутри приложения и работает без интернета.

## Установка IPA через Sideloadly

1. Установите Sideloadly на Windows или macOS.
2. Подключите iPhone кабелем и подтвердите доверие компьютеру.
3. Перетащите файл `LingoSpark-unsigned.ipa` в Sideloadly.
4. Укажите Apple ID и нажмите **Start**.
5. На iPhone включите режим разработчика и доверьтесь профилю Apple ID.

Приложение работает офлайн: Expo Go и постоянное подключение к компьютеру не нужны. Необязательный аккаунт Supabase сохраняет прогресс в облаке; интернет требуется только для входа и синхронизации. При бесплатном Apple ID подпись нужно обновлять каждые 7 дней.

## Создание следующей IPA

Выполните `npm run build:ipa`. Профиль `sideloadly` компилирует arm64-приложение без Apple-подписи и упаковывает его в IPA. Подпись добавляется при установке через Sideloadly.

Релизы Expo Snack для проекта не создаются.
