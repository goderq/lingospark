# LingoSpark для Expo Go

Словарная база построена на открытом частотном англо-русском наборе `shamilfrontend/english-russian-dictionary` (Google 10k, Викисловари CC BY-SA 3.0); внутри приложения хранится локально.

## Запуск только с iPhone

1. Установите **Expo Go** из App Store.
2. Откройте в Safari: https://snack.expo.dev/EHrtvfXZKKvWN0FX4MFiU
3. Нажмите **Open in Expo Go** или **My Device → Open**.

Проект опубликован анонимно в Expo Snack на SDK 58. Его исходный код доступен по этой же ссылке.

## Запуск на iPhone

1. Установите **Expo Go** из App Store.
2. На компьютере откройте терминал в этой папке.
3. Выполните `npm install`, затем `npm run tunnel`.
4. Отсканируйте появившийся QR-код камерой iPhone и откройте его в Expo Go.

Режим `tunnel` работает, даже если компьютер и телефон находятся в разных сетях. Пока приложение открывается через Expo Go, запущенный терминал должен оставаться включённым.

Чтобы запускать приложение только с телефона и без включённого компьютера, проект нужно один раз опубликовать в облаке Expo под бесплатным аккаунтом. Для самостоятельной iOS-сборки и распространения через TestFlight потребуется Apple Developer Program.
