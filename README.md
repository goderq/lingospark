# LingoSpark для iPhone

## Качество разбора и короткие занятия — версия 3.2.0

Текущая версия исходников — 3.2.0, iOS build 39. IPA не собиралась, публикация Expo и отправка GitHub не выполнялись. Ниже сохранена история прежних версий.

На главном экране и в обучении появилось занятие «10 минут»: один учебный этап (либо самопроверка, если этапы уже пройдены), до пяти вопросов повторения по сроку и две письменные реплики этой же темы. Кнопка сразу начинает или продолжает сохранённый шаг. Время приблизительное. Если очередь пуста или времени нет, повторение можно явно пропустить: такой шаг не получает результата. Завершение короткого занятия не выдаёт дополнительную награду и не обходит правила открытия курса. Полный разговор с локальным ИИ доступен отдельно из итога, установка модели для короткого занятия не нужна.

В общей практике и этапах тем используется подробная карточка разбора. При ошибке сразу видны конкретные наблюдаемые отличия: язык, отрицание, пропущенный элемент, лишний элемент или порядок слов. Допустимые альтернативы не попадают в список неправильных вариантов. Сравнение формулировок не выдаётся за доказательство того, что ответ неверен во всех ситуациях. Для выражений курса показываются реальные билингвальные пары; частые ошибки знакомства, Past Simple, окончания -ed и возврата денег получили отдельные пояснения. Для неподготовленных случаев остаётся нейтральное сравнение, а не выдуманное правило.

Закрепление доступно только при наличии связанного задания. Пояснения сгенерированных этапов сохраняют связь с исходным вопросом; добавлены девять проверенных вариантов для знакомства, в том числе после сборки и ввода слов. Задание меняет ситуацию/формулировку, сохраняя навык. Заблокированные темы в обоих списках объясняют, что завершить, и по нажатию ведут к первому необходимому уроку. Рекомендация дня называет конкретный следующий этап.

ИИ получает дополнительную инструкцию следующего хода: ответить на вопрос, предложить конкретный выбор, изменить условия, уточнить деталь или подвести итог. Недавние вопросы передаются как напоминание не повторяться. Это настройка запроса, не переобучение и не гарантия поведения каждой локальной модели. В тематическом чате раскрывается итог по цели: совпадения только с подготовленными образцами в репликах ученика и отдельная самооценка достижения цели. Перефразирование без совпадения не объявляется ошибкой. Итог свёрнут по умолчанию, панель ограничена по высоте и скрывается при клавиатуре. Сохранённые фразы теперь содержат перевод вместо инструкции упражнения.

Число подготовленных примеров слов выросло с 50 до 80. Убрано определение глагола/наречия только по английским суффиксам: оно ошибалось на building/family. Непроверенная часть речи обозначается осторожно. Новые пояснения отображаются и в ранее сохранённой сессии слов; вся база заново вручную не вычитывалась.

Подготовка повторения прекращается после заполнения сессии; при полной проверке памяти не строится индекс всех слов. Карточка объяснения подписана только на действия, а совпадения в ИИ не пересчитываются при каждом токене ответа. В диагностике доступны очистка и копирование локальных замеров. [Отчёт нагрузочной проверки](docs/performance-3.2.md) сравнивает одинаковые очереди на 10 000 записей с 3.1.0. Это тест Node, не измерение скорости или памяти iPhone.

Проверки: `npm run test:learning-quality`, прежние тесты архитектуры, практики, маршрутов, памяти, проверки ответов, облачных правил и сюжетов; аудиты курсов, объяснений и словаря; локальный экспорт JavaScript для iOS. Клавиатура, реальные модели и длительное использование на iPhone требуют отдельной проверки. Ручной GitHub workflow дополнен тестом качества; сборка не запускалась.

## Общая практика и надёжное сохранение — версия 3.1.0

Текущая версия исходников — 3.1.0, iOS build 38. Изменения подготовлены локально. Сборка IPA, публикация Expo и отправка GitHub не выполнялись. Все разделы ниже про прежние версии описывают историю изменений.

Все 43 темы получили пять этапов: объяснение, выражения, слух, сборка и письменный диалог. Всего 603 задания этапов; это расширение существующих материалов, а не 603 полностью новых языковых примера. У каждого разговора свои реплики и ситуация. После пяти этапов открывается отдельная самопроверка по исходным заданиям курса; результат от 80% открывает следующий курс. Старые завершённые курсы сохраняются. Учебное прохождение с разбором остаётся дополнительным режимом.

Повторяющиеся входы в ежедневную и смешанную практику ведут в общий тренажёр: обучение или самопроверка, A1–C1, тема, навык и размер сессии. Пул содержит 1136 записей из курсов и грамматики; в сессию не попадают одинаковые вопросы одного навыка. В обучении помощь помечает ответ как выполненный с подсказкой. В самопроверке и отложенном повторении правильные ответы скрыты до завершения. Короткие проверки не подтверждают CEFR или IELTS Band. За самостоятельный правильный ответ начисляется 1 XP один раз за вопрос в день; повторное прохождение курса не выдаёт повторно его награду.

Единая очередь повторения объединяет ошибки, слова, выбранные фразы из ИИ и проверки памяти курса. Верные самостоятельные ответы назначают следующий срок через 1/3/7/14/30 дней; ошибка или подсказка — через 10 минут. Проверки уроков сохраняют собственное расписание. Слово получает учебную отметку закрепления после нескольких успешных независимых проверок в разные дни, а не после повторных нажатий в одной сессии. Карта навыков показывает фактические результаты, включая последние 50 общих сессий.

Проверка ответов учитывает регистр, пунктуацию, е/ё, подготовленные альтернативы и однозначные английские сокращения. Свободный русский порядок слов проверяется осторожно: перестановка отрицания и значимых предлогов может менять смысл. Полноценного семантического анализатора нет. Структурные аудиты словаря проходят для 4350 основных и 8085 расширенных слов; повторной ручной вычитки всей базы это не означает.

Сохраняются незаконченные общие сессии, слова, времена и академия грамматики. Для текущего локального сохранения хранится предыдущая читаемая копия; если обе повреждены, открывается восстановление вместо автоматического сброса. Экспорт резервной копии имеет версию и контрольную сумму. Облачная запись проверяет revision: при изменениях на двух устройствах автоматическая замена останавливается, показывается сравнение, обе копии сохраняются перед выбором. После переустановки свежий прогресс уступает облачному. Серверная схема и RLS не менялись. Для защиты от старого безусловного способа записи нужно обновить приложение на обоих устройствах.

ИИ получает тему, цель и выражения любого курса. Выбранные фразы можно отправить в повторение; подсказки открываются постепенно. Разбор ограничивается последними целыми репликами, которые помещаются в контекст, и показывает объём разобранной части. Модель не переобучалась. LLM и Whisper используют общую очередь, выгружаются при смене движка и уходе приложения в фон; действует экономный режим контекста по умолчанию. Оценка совпадения распознанного текста не выдаётся за оценку акцента.

Основные экраны загружаются отложенно, каталоги тем и курсов используют виртуальные списки. Сохранения объединяют частые изменения и записываются последовательно. Корневая навигация подписана только на нужные поля прогресса. Локальные замеры переходов, сериализации, запуска речи и первого токена доступны в диагностике. [Отчёт и границы измерений](docs/performance-3.1.md).

Проверено: `test:architecture`, `test:practice`, `test:learning-journey`, `test:exercise-engine`, `test:cloud-sync`, `test:retention`, `test:content-quality`, `test:speech-scheduling`, три проверки мира, аудиты курсов/объяснений/словаря и локальный экспорт JavaScript для iOS. Конкурентная облачная запись проверена на тестовом транспорте; восстановление между двумя реальными авторизованными устройствами, клавиатура, нативные модели и память ещё требуют проверки на iPhone. Автоматическая сборка в GitHub Actions остаётся только ручной (`workflow_dispatch`).

## Обучение как единый маршрут — версия 3.0.0

Пять основных вкладок: «Сегодня», «Обучение», «Жизнь» (полное название — «Английская жизнь»), «ИИ» и «Профиль». Курсы, слова, грамматика и экзамены доступны из «Обучения». Старые переходы к словам и курсам продолжают открывать нужные экраны. На главном убраны надписи «новый каталог/режим», показано состояние облачной синхронизации из существующего сервиса. Серверная схема и политика разрешения конфликтов в этом обновлении не менялись.

Для «Знакомства» написан полный маршрут из пяти этапов: объяснение с простым/подробным режимом, слова в ситуации, слуховые задания, сборка фраз и письменный диалог с Sam. Всего 15 заданий. Следующий этап открывается после результата от 80%. Подсказанные и исправленные ответы не переписывают исходный результат. Текущий вопрос, введённый ответ и уже проверенные ответы сохраняются в прогрессе; повторное завершение одной попытки не начисляет её дважды. Маршрут не открывает следующий курс автоматически: сам урок курса проходится отдельно, после него доступны прежние проверки памяти.

Из маршрута можно открыть локальный ИИ с темой, целью и первой репликой знакомства. Установка модели остаётся добровольной через библиотеку ИИ; учебные этапы работают без неё. Контекст передаётся в системную инструкцию, но качество ответов зависит от установленной модели — модель не переобучалась. В истории сохраняется связь диалога с темой.

В обычных курсах убраны жизни и принудительный перезапуск. Неверные ответы разбираются после основных вопросов; к завершению можно перейти после правильного ответа в разборе. В мини-разговоре ошибка требует повторной реплики и остаётся ошибкой в исходной точности. Черновик курса сохраняет ответы, счёт, порядок вариантов, разбор и шаг разговора. Старый черновик без результатов или черновик от другой версии содержания начинается сначала, чтобы не выдумывать точность. Завершённые уроки сохраняются.

Во временах и академии грамматики также убраны жизни; прохождение засчитывается от 80%. Экзаменационные режимы сохранены. Неиспользуемые переключатели «Строгая проверка» и «Режим испытания», которые не влияли на проверку ответов, убраны из настроек. Дополнительные значения слова скрыты под раскрытием; основной перевод и пример видны сразу. Сам словарь не был заново полностью вычитан.

«Карта навыков» показывает конкретные результаты и источник данных вместо общего процента «освоения». Недостаток данных отмечается явно. Письменный диалог не выдаётся за проверку устной речи, прохождение заданий — за подтверждение CEFR.

Полный формат из пяти этапов пока подготовлен для одной темы. Остальные 42 курса и разделы доступны в существующем формате; их смысловая переработка ещё предстоит. Добавлены замеры первого кадра новых экранов. Проверки: `npm run test:learning-journey`, `npm run test:cloud-sync`, учебные аудиты и экспорт JavaScript для iOS. Нативные переходы, клавиатуру и локальные модели нужно проверить на iPhone. IPA и публикация Expo не запускались.

## Следующий шаг и проверка памяти — версия 2.12.0

Главный экран начинается с трёх действий и объясняет каждую рекомендацию: продолжение курса, проверка памяти (либо диктант до первого пройденного урока), ошибки или слова. Дополнительные баннеры открываются через «Показать все разделы»; каталог и «Английская жизнь» доступны сразу.

После прохождения урока через 24 часа становится доступна отдельная проверка: до пяти вопросов с выбором ответа из этого урока, в случайном порядке. Подсказки, правильные ответы и промежуточная оценка скрыты до завершения. Успешная проверка (от 80%) назначает следующую через три дня; после двух успешных проверок подряд урок получает отметку «Закреплено», дальнейший интервал — семь дней. Неуспех снимает эту отметку и назначает повтор через день. Это учебный индикатор по выборочным вопросам, а не доказательство владения темой.

Старые пройденные уроки получают первую проверку через день после обновления: прошлую дату прохождения не угадываем. Расписание и результаты входят в обычное сохранение прогресса и резервную копию. Проверки не меняют доступ к урокам и не начисляют повторно XP курса. Выход из незавершённой проверки не засчитывает попытку.

Проверка: `npm run test:retention`. Нативный интерфейс на iPhone ещё нужно проверить; IPA не собиралась.

## Качество и замеры — версия 2.11.0

В объяснениях, карточках слов и раскрытых словарных записях доступна отметка «Ошибка в задании». Запись содержит вопрос, ответ, варианты, выбранную реплику и причину. Повторные отметки объединяются, сохраняется не больше 100 записей. В «Профиль → Диагностика» можно просмотреть последние записи и скопировать весь список для разбора. Автоматической отправки разработчику нет.

Диагностика показывает последние 60 локальных замеров: запуск JavaScript, первый кадр экрана слов/словаря, фильтрацию и задержку начала речи. Это измерения текущего устройства и запуска, не обещание конкретной скорости. Нативную задержку на iPhone ещё нужно проверить.

Варианты ответа словесной тренировки вычисляются один раз для карточки, принимаемые переводы исключаются из отвлекающих вариантов. Поиск словаря использует готовый индекс; список подгружается порциями по 100 без прежнего обрезания на 300 словах. Озвучивание не ждёт вызова остановки, когда предыдущая речь не активна.

Проверки: `npm run test:content-quality`, `npm run test:speech-scheduling`. Структурная проверка вариантов не заменяет смысловую вычитку переводов.

## Сценарные разговоры — версия 2.10.0

В миссии аренды после чтения объявления можно обсудить цену, попросить ремонт, договориться о просмотре или отказаться и выбрать другое жильё. Написанные реплики проверяются по подготовленным вариантам без сервера и ИИ. Если формулировка не распознана, персонаж просит уточнить её; это не объявляется доказанной грамматической ошибкой. Для просмотра доступны два времени. Согласованное снижение аренды учитывается в итоговой стоимости; залог не меняется.

Помощь открывается в три шага: ключевое выражение, начало фразы, полный пример. В заданиях трёх жизненных путей первое уточнение проходит без потери жизни. Итог разделяет сюжетный результат и точность практики; в аренде дополнительно показываются понятные реплики, попытки, уточнения и подсказки. Можно повторить поиск, сохранив прежний договор в истории.

Проверка: `npm run test:world-dialogue`. IPA по-прежнему собирается только по отдельной команде.

## Установка IPA через Sideloadly

1. Установите Sideloadly на Windows или macOS.
2. Подключите iPhone кабелем и подтвердите доверие компьютеру.
3. Перетащите файл `LingoSpark-unsigned.ipa` в Sideloadly.
4. Укажите Apple ID и нажмите **Start**.
5. На iPhone включите режим разработчика и доверьтесь профилю Apple ID.

Приложение работает офлайн: Expo Go и постоянное подключение к компьютеру не нужны. Необязательный аккаунт Supabase сохраняет прогресс в облаке; интернет требуется только для входа и синхронизации. При бесплатном Apple ID подпись нужно обновлять каждые 7 дней.

## Создание следующей IPA

### GitHub Actions (ручная сборка)

1. В репозитории откройте **Actions → iOS IPA for Sideloadly**.
2. Нажмите **Run workflow**, выберите ветку `main` и подтвердите запуск.
3. После успешной сборки откройте её страницу и скачайте архив из **Artifacts → LingoSpark-unsigned-IPA-…**.
4. Распакуйте ZIP и установите находящийся внутри `.ipa` через Sideloadly.

Workflow запускается только вручную. Коммиты и загрузка кода не запускают сборку.
Используется виртуальный Mac GitHub (`macos-26`), Xcode и CocoaPods; учётная запись Expo и лимит EAS Build не используются.
Сборка создаёт неподписанный IPA для физического iPhone, не для симулятора. Подпись добавляет Sideloadly при установке. Apple ID, пароль и сертификаты в GitHub загружать не нужно.

Проверены структура workflow, локальная сборка JavaScript и учебные проверки. Первый полный запуск на macOS ещё нужно проверить вручную: Linux-среда не позволяет выполнить Xcode. Доступность и стоимость macOS-минут зависят от текущих условий GitHub Actions и настроек аккаунта.

Скрипт `bash scripts/build-ios-unsigned.sh` можно запустить и на своём Mac после `npm ci`, `npx expo prebuild --platform ios --no-install` и `cd ios && pod install` (затем вернуться в корень проекта).

### Ранее использовавшаяся сборка EAS

Команда `npm run build:ipa` использует EAS Build и его квоту. Профиль `sideloadly` компилирует arm64-приложение без Apple-подписи и упаковывает его в IPA.

Релизы Expo Snack для проекта не создаются.
