# Интерфейс 4.0.0: проверка и ограничения

Дата: 2026-11-17. Исходная версия: `3c105ba` (3.2.0). IPA не собиралась.

## Оформление

Палитры находятся в `src/design/palettes.js`. `ThemeProvider` хранит выбор на устройстве отдельно от учебного прогресса; применяет native Appearance и слушает системные изменения. Основной экран показывается после чтения настройки, чтобы не показать неверную палитру на запуске. При ошибке чтения используется системная тема. Смена темы публикуется через React Context без ключа, который мог бы пересоздать навигацию или поле ввода.

Статические таблицы экранов переведены на `createThemedStyles`: фабрика вычисляется один раз для светлой и один для тёмной схемы, остальные обращения возвращают те же объекты. Ленивые экраны получают актуальную палитру при открытии. Вместо прежних белых текстов и тёмных фонов используются семантические роли. Белый текст сохраняется на специально контрастных фирменных заливках.

Не каждый вспомогательный экран получил уникальную новую композицию: общий дизайн применяется ко всем, а структура главного экрана, обучения, профиля и инструментов чата переработана отдельно. Учебное содержимое, проверки и сюжетные состояния сохраняются.

## Анимация

Появление экрана — 220 мс: прозрачность и перемещение на 8 точек. Заполнение прогресса — 300 мс, масштаб по оси X. Нажатие — короткая пружина масштаба до 0,975. Движение выполняется через native driver; обработчики прекращают анимацию при выходе. Системное Reduce Motion имеет приоритет над пользовательским включением движения. Количество анимированных элементов ограничено: все строки больших списков одновременно не анимируются.

## Проверено автоматически

`npm run test:interface` запускает React renderer с моками нативных представлений, Appearance, AccessibilityInfo, AppState и AsyncStorage. Это не симулятор iOS и не проверка пикселей.

- Светлая, тёмная и системная схемы; приоритет ручного выбора.
- Последовательная запись быстрых изменений оформления и уменьшения движения.
- Ввод остаётся после переключения темы; компонент ввода монтируется один раз.
- Повторное переключение использует два кэшированных набора стилей.
- Основные пары текст/поверхность и контраст подписей основных цветных кнопок — минимум 4,5:1.
- Системное уменьшение движения подавляет переходы, обычные переходы используют native driver.
- Главный экран, обучение, профиль и настройки рендерятся в обеих схемах.
- Незавершённая практика открывается только после кнопки продолжения; введённый ответ сохранён.
- Старый сохранённый маршрут не открывается и удаляется. Возврат background → inactive → active ведёт домой; inactive → active сохраняет текущий экран. XP не изменяются.

Также выполнены прежние проверки маршрутов, упражнений, повторения, архитектуры, словаря, объяснений и сюжетных режимов. Экспорт JavaScript для iOS не проверяет нативную совместимость. Сохраняется известное предупреждение whisper.rn о разрешении корневого импорта через файловую структуру.

## Проверить на iPhone

1. Переключить три оформления на открытых настройках; закрыть приложение и открыть снова. Проверить системную тему при смене режима iPhone, а также строку состояния, клавиатуру и Alert.
2. Оставить частичный ответ в практике, сменить тему и убедиться, что он остался. Отправить приложение в фон: возврат должен открыть «Сегодня». Через явное продолжение восстановить ответ.
3. Открыть карту мира, слова, словарь, грамматику, загрузки моделей и резервные копии в обеих схемах. Проверить текст поверх цветных данных и длинные переводы.
4. Проверить маленький экран, увеличенный системный шрифт, VoiceOver, клавиатуру чата и закрытие панели инструментов ИИ.
5. Включить системное уменьшение движения и пользовательскую настройку. Проверить быстрые переходы, нажатия, прогресс и длительную прокрутку. FPS и память измерить Instruments; таких замеров в рабочей среде нет.

Сборка и установка IPA выполняются только по отдельной команде пользователя. Workflow GitHub остаётся ручным.
