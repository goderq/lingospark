# Словарь 4.2.0

База выросла с 8 085 до 8 363 уникальных английских записей: добавлено 278 слов с переводами и подготовленными двуязычными примерами. Основной набор вырос с 4 350 до 4 628. Вместе с прежними 80 примерами теперь их 358. Это количество слов с примерами, а не утверждение о наличии примера у каждой словарной записи.

Новые записи написаны отдельно в `src/data/wordExpansion.js`. Их ID имеют вид `extra-backpack` и зависят от английского слова. Старые `bank-N`, переводы и транскрипции не перенумеровываются. Расширение подключается к основному и полному набору; сборщик исходного FreeDict/MUSE-словаря не перезаписывает этот файл. Новые слова не получают транскрипций без проверенного источника или выдуманных рейтингов частотности. Уровни A1–C1 служат ориентиром и не являются сертифицированной CEFR-разметкой.

Состояние карточки и фильтры используют одну функцию: неизвестное слово — «Новое»; наступил срок — «Пора повторить»; интервал от 14 дней и минимум три успешных дня при будущем сроке — «Освоено»; остальные — «Учу». Наступивший срок важнее освоенности. Сам просмотр карточки или примера не меняет прогресс. Тренировочные счётчики относятся к выбранной базе без скрытых слов; старые тематические записи не уменьшают количество новых слов другой базы.

Для поиска подготовлена нормализованная строка English + русский перевод. Запрос обрабатывает регистр, пробелы, е/ё и пользовательские переводы. Сначала показываются точное английское совпадение, начало английского слова, начало перевода, затем остальные совпадения. Пустой запрос возвращает исходный массив без сортировки. Поиск откладывается через `useDeferredValue`, чтобы обновление поля ввода не ждало отрисовки результатов.

`FlatList` получает весь результат; виртуализация ограничивает число отрисованных карточек. Удалены срезы и обновления массива через `onEndReached`. Карточка вынесена в `memo` со стабильными действиями и отдельными скалярными признаками; соседние карточки не перерисовываются при раскрытии одного слова. На iOS `removeClippedSubviews` отключён для карточек переменной высоты. На Android оставлен включённым. Подписки на прогресс ограничены данными раздела. В тренировке чтение черновика выполняется один раз, сериализация сессии мемоизирована и не выполняется до начала занятия.

Проверки:

- `npm run test:word-dictionary`: все старые ID и транскрипции, уникальность новых записей, основной и полный наборы, уровни, переводы, связанные примеры, поиск по английскому/русскому/своему переводу, е/ё, приоритет срока повторения.
- `npm run dictionary:core-audit`, `dictionary:learning-audit`, `dictionary:audit`: базовые ограничения словаря, состав наборов и примеры.
- `npm run test:interface`: реальные React-компоненты с подставленными нативными API; полный каталог, поиск, фильтры, отсутствие перерисовок соседних карточек, раскрытие/озвучка примера, три палитры, запуск новой карточки, валидный черновик и принятие правильного перевода.

Замер поиска по 8 363 словам в Node, 60 запросов шести типов, в одном запуске: медиана 1,29 мс, p95 5,72 мс. Значения зависят от нагрузки и не измеряют FPS, память или задержки на iPhone. Перед выпуском IPA нужны проверка длинной прокрутки, раскрытия карточек, поиска с клавиатурой, озвучки и сессии на физическом устройстве. Локальный экспорт JavaScript для iOS не заменяет эти проверки. Сборка IPA и публикация Expo не запускались.
