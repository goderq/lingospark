# Проверка архитектуры 3.1.0

Дата: 2026-11-17. База сравнения: локальный коммит `2b04314` (3.0.0).

## Начальный граф импортов

Команда: `npm run benchmark:architecture`.

| Показатель | 3.0.0 | 3.1.0 |
| --- | ---: | ---: |
| Статически достижимые локальные модули из App.js | 90 | 43 |
| Размер исходников этих модулей, байт | 1 284 677 | 443 298 |
| JSON словаря в начальном графе | нет | нет |

Снижение размера исходников в этом графе — 65%. Анализ исключает пакеты node_modules, ресурсы и динамические импорты. Это не измерение оперативной памяти, размера IPA, FPS или времени запуска iPhone. Отложенные экраны всё равно входят в общий JavaScript-экспорт. Размер итогового Hermes bundle — около 5,3 MB.

## Автоматические проверки

`npm run test:architecture` проверяет последовательную запись, объединение промежуточных состояний, повтор после ошибки диска, несколько одновременных flush, чтение предыдущей копии при повреждении текущей и отказ сбрасывать две повреждённые копии.

Для 100 изменений введённого текста селектор состояния навигации меняется 0 раз. Это проверка подписки на данные, а не профилирование полного интерфейса React на устройстве.

Проверены взаимоисключение LLM/STT, отмена активной работы и освобождение ресурсов, сохранение последней реплики в контексте, ограничение размера анализа, версии и контрольная сумма копии, валидация черновиков слов и грамматики, выборка без повторов даже при размере пула 997.

Конкурентные записи используют реальный клиентский модуль транспорта и тестовую строку Supabase: из двух обновлений одной revision проходит одно, второе получает конфликт. Это не тест двух реальных аккаунтов/устройств. Серверная схема не менялась.

`npm run test:practice` проверяет 1136 записей пула, все уровни и навыки, 43 тематических диалога, самостоятельные/подсказанные ответы, защиту от повторной награды, слияние очереди и отложенное появление карточек. Остальные учебные и словарные проверки перечислены в README.

Локальный `npx expo export --platform ios --output-dir /tmp/lingospark-31-final-js` прошёл. Сохраняется предупреждение whisper.rn об отсутствии корневого exports и переходе к разрешению файла. Нативная совместимость этим экспортом не проверяется.

## Что измерять на iPhone

1. Холодный запуск, переходы к словам и словарю; затем поиск, прокрутка и ввод при большом сохранении. Сравнить медиану/p95 нескольких одинаковых проходов в диагностике.
2. Появление и скрытие клавиатуры в практике и ИИ, возврат к черновику после закрытия приложения.
3. Время старта озвучивания и первого токена каждой модели, переход LLM → Whisper → LLM, уход в фон во время работы. Через Xcode Instruments проверить пик памяти и реакцию на memory pressure.
4. Два устройства: работа офлайн на обоих, соединение, сравнение конфликта, сохранение обеих копий, выбор, повторная синхронизация. Затем переустановка и восстановление из аккаунта. Использовать 3.1.0 на обоих устройствах.

Обещание конкретного ускорения или снижения памяти возможно только после этих измерений. IPA и публикация Expo для проверки не запускались.
