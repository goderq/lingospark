# Нагрузочная проверка 3.2.0

Дата: 2026-11-17. База: `dcfe503` (3.1.0). Команда: `npm run benchmark:learning`. Для сравнения нужна локальная история Git с этим коммитом.

Тест выполняется в Node в рабочей среде. Данные синтетические: 10 000 записей. Для каждой операции — три прогрева и 30 измерений; случайность проверки урока фиксируется для одинакового результата. Состав, порядок карточек и вариантов сравниваются с прежней реализацией. Зависимости и входные данные одинаковы; сравнивается построение очереди.

| Нагрузка | Медиана до, мс | Медиана после, мс | p95 до, мс | p95 после, мс |
| --- | ---: | ---: | ---: | ---: |
| 10 000 слов по сроку, сессия 12 карточек | 8,085 | 3,383 | 24,633 | 6,389 |
| 10 000 записей очереди, сессия 12 карточек | 5,251 | 3,764 | 6,191 | 6,444 |
| Проверка урока + 10 000 слов, сессия 5 карточек | 7,717 | 0,031 | 8,991 | 0,085 |

Медианы снизились во всех трёх случаях этого запуска. p95 общей очереди немного вырос: результаты зависят от сборки мусора и нагрузки среды; обещать одинаковое ускорение нельзя. Основное изменение — прекращение построения после заполнения сессии. Если её целиком занимает проверка урока, индекс 10 000 слов вообще не создаётся.

Дополнительно проверено 1000 выборок по 50 карточек без повторяющихся ID. Тесты качества проверяют переход к правильному предварительному уроку во всех 43 темах, чтение сохранённого короткого занятия, отказ принимать повреждённый план, отличия ответа и исключение реплик ИИ/команд из признаков практики ученика.

Сравнение по подготовленным образцам ИИ пересчитывается при изменении реплик ученика, а не при каждом обновлении потока модели. Карточка объяснения получает только стабильные действия хранилища. Эти изменения не заменяют профилирование React на устройстве.

В «Профиль → Диагностика» кнопка «Новый замер» очищает длительности текущего запуска. После неё повторить переходы к словам, поиск и озвучивание, затем вернуться и обновить показатели. «Скопировать замеры» экспортирует версию, платформу, длительности и состояние очереди моделей; тексты ответов и данные аккаунта в этот отчёт не входят. Метрики не измеряют память/FPS.

На физическом iPhone ещё нужны: длинная сессия слов, большой прогресс, клавиатура на новых экранах, восстановление шага после закрытия, чат с каждой моделью, переключение LLM/Whisper и замеры памяти в Instruments. Сборка IPA для этих проверок не запускалась.
