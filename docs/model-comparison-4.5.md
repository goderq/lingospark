# Сравнение моделей на iPhone

На одном iPhone скачай Llama 3.2 1B, Gemma 3 1B и Llama 3.2 3B. Для каждого прогона выбери A2 и одинаковые настройки экономии и редактуры. Закрой другие ресурсоёмкие приложения и дай телефону остыть между прогонами. Начинай новый чат для каждой модели.

В режиме «Живой» отправляй эти десять реплик по порядку. Замерь время от отправки до появления полного ответа. Отдельно запиши время первого запуска модели.

| № | Реплика | Что проверить |
| --- | --- | --- |
| 1 | Hi | Естественное короткое приветствие на английском |
| 2 | What? | Уточняет предыдущую реплику простыми словами |
| 3 | Let's talk about a job interview. | Переключается на работу |
| 4 | I have experience in customer support. | Реагирует на конкретный опыт |
| 5 | I worked at a small hotel for two years. | Учитывает должность и опыт |
| 6 | Yesterday I help a guest find a taxi. | Если исправляет, предлагает helped и объясняет почему |
| 7 | What question could I ask the interviewer? | Даёт естественный пример вопроса |
| 8 | Translate your suggestion into Russian. | Переводит свой пример |
| 9 | Let's continue in English. | Возвращается к английскому |
| 10 | What experience did I tell you about? | Вспоминает работу в отеле и поддержку клиентов |

В режиме «Собеседование» открой подсказку первого шага и произнеси или напечатай фразы ниже. После уточнения должно остаться первое задание. Затем каждый ответ должен вести к следующему шагу.

1. `What?`
2. `I am have experience working with customers.`
3. `Last year, I helped a customer solve a problem.`
4. `Could you tell me about the team?`

Разбор должен показать фразу о клиенте, исправление `I have experience working with customers.` и одно задание на конструкцию `I have experience`. Во время ввода проверь, что поле и кнопка отправки видны над клавиатурой.

| Модель | Первый запуск | Медиана ответа | Реплики по теме из 10 | Язык и повторы | Нагрев и сбои |
| --- | --- | --- | --- | --- | --- |
| Llama 3.2 1B | | | | | |
| Gemma 3 1B | | | | | |
| Llama 3.2 3B | | | | | |

Сначала сравни количество удачных ответов и стабильность. При близком результате выбери более быструю модель. Физический прогон ещё предстоит.
